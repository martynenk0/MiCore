    Оплата · ЮKassa

    Подключи ЮKassa для оплаты тарифов Creator / Vision / Business. Для автоплатежей нужен бэкенд, который создаёт платёж через API ЮKassa и возвращает confirmation_url.

    POST /create-payment → {confirmation_url}. GET /check-payment?plan= → {paid:true}.
    Тестовый режимКнопка «активировать без оплаты» в окне оплаты
